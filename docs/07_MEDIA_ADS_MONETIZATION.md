# 07 — मीडिया, विज्ञापन एवं मुद्रीकरण (Media, Ads & Monetization)
**परियोजना:** खबरी दोस्त (Khabri Dost) | `khabridost.com`  
**प्रयोजन:** मल्टीमीडिया पाइपलाइन, क्लाइंट-साइड वेबपी संपीड़न, वॉटरमार्किंग और विज्ञापन मुद्रीकरण रणनीति।

---

## 1. मीडिया प्रसंस्करण एवं भंडारण पाइपलाइन (Media Processing Pipeline)

खबरी दोस्त में छवियों की गुणवत्ता और तीव्र लोडिंग सुनिश्चित करने के लिए एक स्वचालित क्लाइंट-साइड मीडिया पाइपलाइन लागू है:

### 1.1 क्लाइंट-साइड WebP संपीड़न (In-Browser Compression)
`MediaLibraryModal.tsx` और `ArticleEditorModal.tsx` में HTML5 Canvas API का उपयोग करके छवियों को अपलोड होते ही संपीड़ित किया जाता है:
- **अधिकतम चौड़ाई:** 1200px (डेस्कटॉप एचडी मानक)।
- **पहलू अनुपात (Aspect Ratio):** 16:9 मानक आलेख अनुपात (Letterbox/Crop)।
- **प्रारूप (Format):** `image/webp`।
- **गुणवत्ता कारक (Quality Factor):** 0.82 (82% गुणवत्ता, जो बिना दृश्य हानि के 70% तक फ़ाइल का आकार कम कर देती है)।
- **परिणाम:** 5MB की सामान्य जेपीईजी छवि 150KB-250KB के कुशल WebP में परिवर्तित हो जाती है, जिससे मोबाइल नेटवर्क पर भी पृष्ठ पलक झपकते ही लोड होता है।

### 1.2 स्वचालित वॉटरमार्किंग (Automated Watermark Engine)
छवि संपीड़न के बाद, कैनवास रेंडरर स्वचालित रूप से ब्रांड पहचान लागू करता है:
- **वॉटरमार्क टेक्स्ट:** "Khabri Dost" (खबरी दोस्त)
- **स्थिति:** नीचे दायां कोना (`bottom-right`, 20px पैडिंग)
- **ओपेसिटी (पारदर्शिता):** 65% सेमी-ट्रांसपेरेंट व्हाइट विथ 1px ब्लैक शैडो
- **उद्देश्य:** सोशल मीडिया पर छवियों की अनधिकृत चोरी या दोबारा पोस्टिंग को रोकना।

## 2. विज्ञापन स्लॉट्स एवं प्लेसमेंट आर्किटेक्चर (Ad Placement Architecture)

पोर्टल में मुद्रीकरण (Monetization) के लिए पूर्व-निर्धारित रणनीतिक विज्ञापन स्थान (Ad Slots) उपलब्ध हैं, जिन्हें `src/components/admin/AdManagementTab.tsx` से नियंत्रित किया जाता है:

```
┌────────────────────────────────────────────────────────────────────────┐
│ [शीर्ष हेडर लीडरबोर्ड] (728x90 Desktop / 320x50 Mobile)                 │
└────────────────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────┐ ┌──────────────────────────────┐
│                                       │ │ [साइडबार स्टिकी टॉवर]        │
│ [एकल समाचार सामग्री (Article Body)]   │ │ (300x600 या 300x250)         │
│                                       │ │                              │
│ ...पैराग्राफ 1 व 2...                 │ │ [प्राइवेट स्पॉन्सर बैनर]     │
│ ┌───────────────────────────────────┐ │ │                              │
│ │ [इन-आर्टिकल मध्य विज्ञापन]         │ │ │                              │
│ │ (300x250 / रिस्पॉन्सिव बैनर)       │ │ │                              │
│ └───────────────────────────────────┘ │ │                              │
│ ...पैराग्राफ 3 व 4...                 │ │                              │
│                                       │ └──────────────────────────────┘
└───────────────────────────────────────┘
┌────────────────────────────────────────────────────────────────────────┐
│ [पादलेख विज्ञापन बैनर (Footer Banner)] (970x90 या 728x90)              │
└────────────────────────────────────────────────────────────────────────┘
```

## 3. विज्ञापन स्लॉट तकनीकी विनिर्देश (Ad Slots Technical Specification)

| स्लॉट पहचानकर्ता (Slot ID) | स्थान (Location) | अनुशंसित आकार | समर्थित प्रकार (Types) | सार्वजनिक कंपोनेंट |
|---|---|---|---|---|
| `ad-header-top` | हेडर के ठीक नीचे, नेविगेशन से पहले | 728x90 (Desktop) / 320x50 (Mobile) | Google AdSense, कस्टम बैनर इमेज + लिंक | `Header.tsx` |
| `ad-article-inline` | समाचार आलेख के दूसरे पैराग्राफ के बाद | 300x250 (Medium Rectangle) / Responsive | Google AdSense, स्थानीय प्रायोजक | `ArticlePageView.tsx` |
| `ad-article-bottom` | समाचार समाप्त होने पर, संबंधित खबरों से पहले | 728x90 / 300x250 | वीडियो विज्ञापन, रिकमेंडेशन नेटवर्क | `ArticlePageView.tsx` |
| `ad-sidebar-sticky` | डेस्कटॉप स्टिकी साइडबार विजेट | 300x600 (Half Page) / 300x250 | डायरेक्ट स्पॉन्सरशिप, एफिलिएट | `ArticlePageView.tsx` |
| `ad-footer-bottom` | पादलेख के ठीक ऊपर | 728x90 / 970x90 | AdSense, नेटिव स्पॉन्सर | `Footer.tsx` |

## 4. मुद्रीकरण प्रबंधन क्षमताएं (Monetization Controls in Admin)

1. **द्वि-मोड विज्ञापन समर्थन:**
   - **मोड 1 — Google AdSense:** प्रकाशक क्लाइंट आईडी (`ca-pub-XXXXXXXXXXXXXXXX`) और विज्ञापन स्लॉट आईडी डालकर सीधे ऑटो-एड्स या फिक्स्ड स्लॉट सक्षम कर सकते हैं।
   - **मोड 2 — डायरेक्ट प्राइवेट स्पॉन्सरशिप (Direct Sponsored Banners):** स्थानीय व्यापारियों और ब्रांड्स के लिए बैनर इमेज अपलोड, लक्षित यूआरएल (Click-through URL), 'Sponsored' बैज और समाप्ति तिथि (Expiry Date) निर्धारित की जा सकती है।
2. **क्लिक एवं प्रदर्शन ट्रैकिंग (Impression & CTR Tracking):**
   - प्रत्येक प्राइवेट विज्ञापन स्लॉट के लिए प्रदर्शन संख्या (Impressions) और क्लिक संख्या (Clicks) का स्थानीय संग्रह, जिससे संपादकीय दल विज्ञापनदाताओं को सटीक रिपोर्ट प्रदान कर सके।
3. **एड-ब्लॉकर अनुकूलता:**
   - विज्ञापन स्लॉट्स में स्पष्ट `ad-slot-container` क्लास है जो सामग्री टूटने पर खाली स्थान को छिपा देती है, जिससे पाठकों का अनुभव खराब न हो।
